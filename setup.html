安装修复说明（Linux / Docker）

常规出图和可视化编辑支持服务端 0.4.0+；Large 高清重画需要 0.6.0+。只更新前端即可恢复旧服务端支持的功能。两份扩展同时启用时，回到新版扩展设置，点击“停用旧离线版并刷新”。

酒馆的“更新扩展”只更新前端目录。若服务端缺失或需要 Large，请在运行酒馆的机器（Docker 则在容器中）执行一次下面的更新，再重启酒馆。把路径替换成自己的实际路径：

node "/path/to/SillyTavern/data/default-user/extensions/SillyNAI/install.mjs" "/path/to/SillyTavern" --server-only
“为所有用户安装”的扩展通常位于 public/scripts/extensions/third-party/SillyNAI；为当前用户安装的位于 data/用户名/extensions/SillyNAI。Docker 使用容器内的路径，plugins 目录需持久化。--server-only 更新服务端，保留现有 Git 前端、账号密钥和聊天。

3 · 回到小说

    
打开酒馆「扩展 → NovelAI 小说配图」。默认已经启用绘图要求，模型会在小说中输出 <nai_image> 指令。勾选「回复完成后自动出图」即可自动配图；也可以保留手动生成。

    如果你想自己修改预设，可关闭「自动向文字模型加入绘图要求」，并使用扩展里的「复制预设指令」。这两种方式使用同一套图片接口。
